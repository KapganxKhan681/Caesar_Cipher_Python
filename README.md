# 🔐 Caesar Cipher Tool / Sezar Şifreleme Aracı

### 🌍 English
This is a simple Python script developed to understand the basics of cryptography, loops, and ASCII character manipulations in Python. It can encrypt and decrypt messages based on a user-defined shift key.

#### 🚀 Features
* Encrypts plain text into cipher text.
* Decrypts cipher text back to plain text.
* Ignores spaces and special characters during shift.
* Dual-language code comments (EN/TR).

#### 💻 How to Run
`python caesar_cipher.py`

---

### 🇹🇷 Türkçe
Python'da kriptolojinin temellerini, döngüleri ve ASCII karakter işlemlerini anlamak için geliştirilmiş basit bir script'tir. Kullanıcı tarafından belirlenen kaydırma anahtarına göre mesajları şifreleyebilir ve şifrelerini çözebilir.

#### 🚀 Özellikler
* Düz metni şifreli metne dönüştürür.
* Şifreli metni tekrar düz metne çözer.
* Kaydırma esnasında boşlukları ve özel karakterleri korur.
* Çift dilli kod yorum satırları içerir (EN/TR).

#### 💻 Nasıl Çalıştırılır
`python caesar_cipher.py`
